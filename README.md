# Semiconductor Vocabulary Dashboard

Static flashcard web dashboard for semiconductor vocabulary learning.

## Files
- `index.html`
- `styles.css`
- `app.js`
- `seed-data.js`

## Deploy
Upload this folder to GitHub Pages, Netlify, or Vercel.

## Privacy
The seed deck is sanitized for public sharing: local paths, source note paths, personal vault names, and private usage metadata were removed. Learning progress is stored only in each visitor browser localStorage.
